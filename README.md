# Music Mod

## Description
a mod that will change the music depending on what the player is doing at the moment. Will allow for custom .ogg files to be uploaded and attached to a given action by a user to play.

## Actions
- Fishing:
    Plays some custom music while fishing
- Building:
    not implemented
- Fighing (for extended periods):
    not implemented
- Boating
    not implemented

whatever else i can think of. Implementation is fairly straight forward and a great way to start learning how this game that i have played for over 12 years works
